# Tomohiko Maruo - Research Website

Static personal research website for GitHub Pages.

## Publish
1. Create a **public** GitHub repository named `tomotomomaruo-lab.github.io`.
2. Upload `index.html` and `style.css` to the repository root (main branch).
3. In Settings > Pages, select **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
4. Visit https://tomotomomaruo-lab.github.io/ after deployment.

## Before using for grant registration
- Replace the placeholder in Profile & Contact with verified institutional affiliation, title, and professional contact.
- Verify the selected-publication bibliographic entries, especially the Cell Reports DOI.
- Confirm the public URL loads on a logged-out browser.
- Do not publish unpublished experimental findings.
